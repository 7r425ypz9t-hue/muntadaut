# مكتبة المنتدى المرئية — muntadaut

منصة تعلّم بأسلوب نتفليكس فوق أرشيف قناة **المنتدى الإسلامي بالشارقة** على يوتيوب ([@almuntadaalislami](https://www.youtube.com/@almuntadaalislami)).
تضم 2,813 مادة و330 برنامجًا و291 محاضرًا، مصنّفة في 16 علمًا.

## ما الذي تقدّمه

**تجربة المشاهدة**
- واجهة رئيسية على نمط نتفليكس:
  - عرض متتابع للبرامج المميزة، مع زر لإيقافه.
  - صفوف أفقية قابلة للتمرير: تابع التعلّم، قائمتي، لأنك شاهدت، أكثر 10 برامج إقبالًا، جديد المنتدى، ابدأ من هنا، وصفّ لكل علم.
  - بطاقة معاينة تتوسّع عند تمرير المؤشر فوقها.
- نافذة تفاصيل لكل برنامج:
  - الحلقات مقسّمة إلى أجزاء.
  - نسبة إنجازك في البرنامج.
  - برامج مشابهة.
- مشغّل مدمج:
  - يستأنف من حيث توقفت.
  - يشغّل الحلقة التالية تلقائيًا مع عدّ تنازلي.
  - يتيح اختيار سرعة التشغيل والانتقال السريع داخل المحاضرات الطويلة.
  - يعمل باختصارات لوحة المفاتيح.
- توصيات مخصّصة ونسبة «تطابق» تُحسب داخل المتصفح (TF-IDF وتشابه جيب التمام) من تاريخ مشاهدتك.
- ملفات متعدّدة للمتعلّمين على الجهاز نفسه.

**أفضل ممارسات التعلّم الإلكتروني**
- 10 مسارات تعلّم متدرّجة من التأسيس إلى التخصص، لكلٍّ منها مخرجات تعلّم.
- تصنيف كل برنامج حسب المستوى (تأسيسي/متوسط/متقدم) والجمهور.
- متابعة الإنجاز على مستوى الدرس والبرنامج والمسار.
- ملاحظات مرتبطة بتوقيت المقطع، تعود إليها بنقرة.
- صفّ «حان وقت المراجعة» للمراجعة المتباعدة بعد يوم وأسبوع وشهر.
- هدف أسبوعي بالدقائق بدل سلاسل الأيام.
- تصدير بيانات التعلّم واستيرادها.

**التقنية**
- ملف HTML واحد، بلغة JavaScript المجرّدة ودون أدوات بناء.
- تطبيق قابل للتثبيت (PWA) مع عامل خدمة للعمل دون اتصال.
- تحميل كسول للصور، و`content-visibility` للصفوف.
- مشغّل YouTube IFrame API عبر `youtube-nocookie`.
- لا خادم ولا تتبّع: كل بيانات المتعلّم في `localStorage`.

## النشر على GitHub Pages

من **Settings ← Pages** اختر: Source = *Deploy from a branch*، وBranch = `main`، وFolder = `/ (root)`.
بعد ذلك تصبح المنصة متاحة على `https://7r425ypz9t-hue.github.io/muntadaut/`.

## التحديث

الملفات المصدرية في مجلد `source` على جهاز المُعِدّ: `app.js` و`app.css` و`shell.html` و`build.py`.
تشغيل `python build.py` يعيد توليد هذا المجلد.
