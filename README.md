# مكتبة المنتدى المرئية — muntadaut

فهرس تفاعلي لكل ما نشرته قناة **المنتدى الإسلامي بالشارقة** على يوتيوب
([@almuntadaalislami](https://www.youtube.com/@almuntadaalislami)): المحاضرات والدورات والندوات، مصنّفة حسب العلم والمحاضر والبرنامج، مع الكلمات المفتاحية ورابط مباشر لكل مادة.

الصفحة ملف واحد مستقل (`index.html`) تضم البيانات كاملة، ولا تحتاج إلى خادم أو قاعدة بيانات.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًّا باسم `muntadaut` في حسابك على GitHub.
2. ارفع محتويات هذا المجلد (`index.html` و`.nojekyll` و`README.md`) إلى الفرع `main`.
3. من **Settings ← Pages** اختر: Source = *Deploy from a branch*، Branch = `main`، Folder = `/ (root)`، ثم احفظ.
4. بعد دقيقة تقريبًا تصبح اللوحة متاحة على:
   `https://<اسم-حسابك>.github.io/muntadaut/`

## تحديث البيانات

أعد توليد `index.html` بسكربتات الاستخلاص نفسها، ثم استبدل الملف في المستودع.

## الأقسام

- **المكتبة**: بحث عربي يتجاهل الهمزات والتشكيل، مع تصفية بالعلم والمحاضر ونوع البرنامج والسنة ونوع المادة.
- **البرامج والدورات**: بطاقة لكل قائمة تشغيل، فيها عدد الحلقات والساعات والمدة الزمنية.
- **المحاضرون**: جدول قابل للفرز، فيه النشاط عبر السنين.
- **التحليلات**: الإنتاج السنوي، والعلوم، وخريطة العلوم عبر السنين، والكلمات المفتاحية، وقراءات تحليلية.
